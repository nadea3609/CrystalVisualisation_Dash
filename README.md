# CrystalVisualisation_Dash
Code repository for MSc project "Interactive Visualisation of Crystals"

Main stable branch

## Required packages:

Dash

Numpy

Plotly:

plotly graph objects

plotly_gif (third party, needs to be installed separately from plotly official packages)

https://github.com/dylanwal/plotly_gif/blob/master/README.md

Sqlite3 (requires SQLite third party library to be installed)

os (only for database_scan.py, which is not required for core operation of app)

glob (only required for database_scan.py)
## Installation

### Before running 
extract the database from "cod_complete.zip" and place in working python directory alongside the app's python scripts and the assets folder

Install the packages required for the app as listed above

Run the "Dash_app.py" in any python interpreter and paste the IP output into the terminal into any browser (although interpreters such as VScode support native running of the app)
